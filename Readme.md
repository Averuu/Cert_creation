### Подготовка к использованию
1. В перовй строке email.txt указывается email, с которого будет отправляться почта, во второй — пароль от этой почты или пароль для приложений, а в третьей — адрес SMTP-сервера. Проверяются только первые три строки этого файла
2. В одной директории с программой должны лежать оба шрифта (Montserrat-Bold.ttf и Montserrat-Medium.ttf), email.txt и шаблон сертификата nameless.png. Готовые сертификаты после их создания сохраняются в той же директории
3. Если при создании или отправке сертификата появляется ошибка, то она указываются в UI
4. В первом окне нужно вставлять имена, почту и так далее вместе с ID из формы, так как наличие ID во вставленном тексте уже предусмотрено
5. Второе окно, которое появляется после нажатия на кнопку "Отправить сертификаты", нужно лишь для того, чтобы убедиться, что все сертификаты уходят на верные адреса. Изменить там уже ничего нельзя

P.S.: Nameless.png был изменён на белый прямоугольник в целях предотвращения создания фальшивых сертификатовЫ
